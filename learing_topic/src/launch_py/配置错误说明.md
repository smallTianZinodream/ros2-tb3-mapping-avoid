## 发现的错误

### 1. `package.xml` 写错了（严重）

**问题：** 把多段 `<launch>...</launch>` 内容直接粘贴进了 `package.xml`。

**为什么错：** `package.xml` 只能写包名、依赖、维护者等信息，**不能**写 launch 启动逻辑。launch 内容必须放在 `launch/` 目录下的 `.xml / .yaml / .py` 文件里。

**表现：** 依赖解析可能异常，包元数据不规范。

**修正：** 删除 `package.xml` 中所有 `<launch>` 块，只保留依赖声明。

---

### 2. `launch/yaml/turtlesim_launch.yaml` 格式损坏（严重）

**问题：**
- 一个文件里出现了多个顶层 `launch:`（YAML 不合法）
- 缩进混乱（`param`、`group`、`push-ros-namespace` 层级错误）
- 混入了课程中文说明文字（如“Launch的XML和YAML实现_文件包含”）
- `include` 引用了不存在的包：`launch_cpp`

**为什么错：** ROS 2 YAML launch 必须是合法 YAML，且只能有一个顶层 `launch:` 列表。

**修正：**
- 重写为合法的基础启动文件 `turtlesim_launch.yaml`
- 把参数、命名空间、文件包含拆成独立文件：
  - `param_launch.yaml`
  - `group_launch.yaml`
  - `include_launch.yaml`
- `include` 改为引用本包 `launch_py`，不再依赖不存在的 `launch_cpp`

---

### 3. 引用了不存在的包 `launch_cpp`（严重）

**问题：** include 路径写成：

```text
$(find-pkg-share launch_cpp)/launch/xml/param_launch.xml
$(find-pkg-share launch_cpp)/launch/yaml/param_launch.yaml
```

**为什么错：** 工作空间里没有 `launch_cpp` 包，运行 include 会找不到文件。

**修正：** 改为：

```text
$(find-pkg-share launch_py)/launch/xml/param_launch.xml
$(find-pkg-share launch_py)/launch/yaml/param_launch.yaml
```

## 当前可用 launch 文件

```bash
cd ~/learing_topic
source /opt/ros/jazzy/setup.bash
colcon build --packages-select launch_py
source install/setup.bash
```

基础双窗口：

```bash
ros2 launch launch_py turtlesim_launch.py
ros2 launch launch_py turtlesim_launch.xml
ros2 launch launch_py turtlesim_launch.yaml
```

参数传参：

```bash
ros2 launch launch_py param_launch.xml
ros2 launch launch_py param_launch.yaml bg_r:=100
```

命名空间分组：

```bash
ros2 launch launch_py group_launch.xml
ros2 launch launch_py group_launch.yaml
```

文件包含：

```bash
ros2 launch launch_py include_launch.xml
ros2 launch launch_py include_launch.yaml
```

---

## 记忆点

1. **launch 内容写在 `launch/` 目录，不要写进 `package.xml`**
2. **YAML 只能有一个顶层 `launch:`，缩进必须正确**
3. **`include` 只能引用真实存在的包路径**
4. **改完 launch / setup 后要重新 `colcon build` 并 `source install/setup.bash`**
